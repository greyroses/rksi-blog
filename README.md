# Учебный блог

Учебное Django-приложение. Все посетители читают публикации, а создавать и изменять их может только авторизованный автор собственной записи.

## Возможности

- публичная главная с новыми публикациями сверху и понятным пустым состоянием;
- регистрация, вход и безопасный выход через POST;
- создание публикаций с автоматическим назначением автора;
- редактирование только собственных публикаций: чужой или отсутствующий ID возвращает 404;
- административный интерфейс с поиском и фильтрами по публикациям.

## Локальный запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Для добавления учебных публикаций через админ-панель сначала выполните `.venv/bin/python manage.py createsuperuser`, затем перейдите на `/admin/`.

## Проверка

```bash
.venv/bin/python manage.py check
.venv/bin/python manage.py test
```

## Запуск в Docker

1. Создайте `.env` из примера: `cp .env.example .env`.
2. Замените `SECRET_KEY`, укажите IP/домены в `ALLOWED_HOSTS` и при необходимости `PORT`.
3. Выполните `docker compose up -d --build`.

После запуска блог доступен по `http://<IP-сервера>:<PORT>/`; стандартный порт — `8002`.

SQLite-база сохраняется в именованном Docker-томе `blog_data`: обычный `docker compose down` её не удаляет. Для резервной копии используйте `docker compose cp web:/data/db.sqlite3 ./blog-backup.sqlite3`. Команда `docker compose down -v` удаляет том вместе с данными.

Не добавляйте в репозиторий `.env`, `db.sqlite3`, виртуальное окружение и реальные пользовательские данные.
